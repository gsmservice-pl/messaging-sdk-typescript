# Price

The pricing result for a single message, returned as part of an HTTP 200 response.

## Example Usage

```typescript
import { Price } from "@gsmservice-pl/messaging-sdk-typescript/models/components";

let value: Price = {
  error: null,
  cid: "custom-id-A44445T",
  type: 1,
  recipient: "+48999999999",
  sender: "Bramka SMS",
  parts: 1,
  unicode: true,
  flash: false,
  price: 0.16,
};
```
